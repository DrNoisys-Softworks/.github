# DrNoisys Softworks

We're a small software workshop building tools for tabletop GMs, the kind of thing you build
because you needed it yourself first.

## GM-Scriptorium

A compiled CLI that turns your Obsidian-style campaign vault into a player-safe website, on top
of the [gm-apprentice](https://github.com/AntTheLimey/gm-apprentice) generator, with leak checks
so your GM notes never end up somewhere a player can see them.

[github.com/DrNoisys-Softworks/gm-scriptorium](https://github.com/DrNoisys-Softworks/gm-scriptorium)
